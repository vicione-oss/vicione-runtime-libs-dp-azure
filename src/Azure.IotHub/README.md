# Azure Iot Hub DataPort [↩](./../../README.md)

DataPort for Azure Iot Hub

## Configuration - Usage

### Prerequisites

- Access to an Azure account
- Access to an Azure subscription

### Setup

1. Go to Azure and sign in.
2. Navigate to the **IoT Hub** service.
3. Create an IoT Hub.
4. Go to the new IoT Hub.
5. Go to **Overview**.
6. Under **Hostname**, you will find the address for the hub.
7. Go to **Security settings** -> **Shared access policies**
8. Select the policy **iothubowner**, this is the **Shared Access Signature Key Name**.
9. Here is the **Primary Key**, which is the **Shared Access Signature Key**.
