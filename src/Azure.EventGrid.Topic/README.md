# Azure EventGrid Topic DataPort [↩](./../../README.md)

DataPort for Azure EventGrid Topic

## Configuration - Usage

### Prerequisites

- Access to an Azure account
- Access to an Azure subscription

### Setup

1. Go to Azure and sign in.
2. Navigate to the **Event Grid** service.
3. On the Event Grid page, under **Custom Events**, go to Topics.
4. Create a Topic.
5. Go to the new Topic.
6. Go to **Overview**.
7. Under **Topic Endpoint**, you will find the address for the Topic.
8. Go to **Settings** -> **Access Keys**
9. Here you will find the access key.
